# Шаблон и правила написания базы знаний GruVPN

Чанкер режет базу так: **каждая `### подтема` = один отдельный чанк** для поиска.
`## Тема` без подтем = один большой чанк (так писать не надо). Чем мельче и точнее
подтема — тем точнее поиск и меньше «плавающих» ответов.

## Как устроен один чанк

```
## NN. Крупная тема (группа)

**Запросы:** широкие фразы по всей теме; синонимы; опечатки

### NN.M Короткая конкретная подтема (один сценарий/вопрос)

**Запросы:** точные фразы именно этой подтемы; как это пишет пользователь; опечатки; транслит

Короткий самодостаточный ответ на 1 сценарий. Точные названия кнопок в «кавычках».
Точные официальные названия приложений (Happ, Incy, Hiddify — без транслита и скобок).
Если по этому вопросу нужен сотрудник — прямо написать: «передать оператору (handoff)».
```

## Правила

1. **Одна подтема — один сценарий.** Не смешивай «подключение» и «диагностику» и «трафик» в одном `###`. Разнёс — стало точнее.
2. **Размер `###`:** примерно 60–200 слов. Если больше — дели на под-под-сценарии (`### NN.M`).
3. **`**Запросы:**` обязательны на каждом `###.`** Пиши так, как реально спрашивает пользователь: живые фразы, синонимы, опечатки, транслит («вупен», «хапп», «винда», «симка»). Разделяй `;`. Чанк наследует и `Запросы:` родительской `##`, и свои.
4. **Самодостаточность.** Подтему должно быть понятно без соседних. Родительский заголовок `##` подставляется автоматически как контекст — дублировать его в тексте не нужно.
5. **Только факты.** Точные кнопки/ссылки/цены/названия. Нет данных — не выдумывай, пиши «передать оператору (handoff)».
6. **Названия приложений** — только официально: `Happ`, `Incy`, `Hiddify`, `Karing`. Без «Хаддифай (Hiddify)».
7. **Явные запреты** оставляй строкой `⛔ Запрет: ...` — они помогают ответчику не врать.
8. **Handoff-подсказки** внутри подтемы, где нужен человек: оплата/возврат/двойное списание/перенос аккаунта/утёкший ключ/нестандартная настройка — «передать оператору (handoff)».

## Заполненные примеры (можно копировать и править)

## 17. Устройства: лимиты, удаление одного устройства, полный сброс и HWID

**Запросы:** лимит устройств; сколько устройств; убрать устройство; сбросить устройства; заблокировать устройство; чужие устройства; HWID

### 17.1 Заблокировать доступ конкретному устройству

**Запросы:** заблокировать устройство; закрыть доступ одному устройству; отключить чужой телефон; убрать одно устройство из подписки

Отдельной блокировки одного устройства в GruVPN нет. ⛔ Запрет: не обещать «ограничить доступ одному устройству» — такой функции нет.
Что реально можно:
1. Перевыпустить ключ — старая ссылка перестанет работать, все прежние устройства отключатся, останется добавить нужные заново.
2. Либо полный сброс списка устройств, затем подключить заново только свои.
Сначала уточни цель: ссылка попала в общий доступ или нужно отключить лишние устройства — от этого зависит, что советовать.

### 17.2 Только «Авто-выбор» / не появился список серверов

**Запросы:** только авто-выбор; нет списка серверов; одна локация; пропали сервера; мало серверов

Обычно это значит, что подписка добавлена не полностью. ⛔ Запрет: не предлагать белые списки в этом случае.
1. Обновить подписку кнопкой с круглой стрелкой рядом с названием подписки в приложении.
2. Если не помогло — удалить подписку в приложении и добавить заново по «Ссылка для подключения».

## 11. Windows: общая диагностика, клиенты и версии

**Запросы:** Windows; винда; ПК; ноутбук; не работает на windows

### 11.1 Старые версии Windows (7/8)

**Запросы:** Windows 7; Windows 8; винда 8; старый виндовс; какой клиент на windows 7

На старых Windows наши основные клиенты могут не подойти. ⛔ Запрет: не утверждать, что Happ/Incy работают на Windows 8.
Karing обычно ставится на Windows 7 и новее; Hiddify тоже работает, но с ним чаще бывают проблемы. Если пользователь на Windows 7/8 и стандартный клиент не идёт — предложить Karing, а при сохранении проблемы передать оператору (handoff).

## После правки базы — переиндексация

1. Загрузить обновлённый `.md` в панель.
2. Сделать полную переиндексацию, чтобы убрать старые крупные чанки: `DELETE /api/kb` (кнопка полного сброса КБ), затем загрузить базу заново. Иначе в поиске останутся и старые «толстые» чанки, и новые.
