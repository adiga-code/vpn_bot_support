# Brag Plan: VPN Хелпдеск — преимущества для VPN-проектов

## Inspection rubric (Step 1)

1. **What is the app?** Панель поддержки для VPN-сервисов: тикеты из Telegram, ИИ отвечает по
   базе знаний, оператор дорешает шаблонами, карточка клиента показывает аккаунт целиком —
   и позволяет менять его прямо из переписки.
2. **Most impressive claim (для владельца VPN).** Оператору не нужна вторая панель: продлить
   подписку, докупить трафик, сменить локацию, сбросить устройства и забанить можно из того же
   окна, где идёт разговор (`app/customer.py`, `ACTIONS`).
3. **Visual hook.** Экран «Статистика»: график «Обращения по дням» с синей заливкой
   `#4F8EF7` и карточки метрик на `#0d0d12`.
4. **What to show from the actual UI.** Экран статистики (карточки + график + тепловая карта),
   пузырь ИИ с бейджем «ИИ», экран «База знаний» с чанками и ключевыми фразами, панель шаблонов
   по «/», карточка клиента с вкладками, ряд действий над аккаунтом + форма + тост.
5. **Shortest satisfying video.** 25s: шесть возможностей, по одной читаемой строке на каждую.
6. **Tone.** Preset `app-store`. Direction: «чистая витрина продукта для владельца VPN-сервиса».
7. **Audio.** Тёплый деловой бед (vol-11, 114.84 BPM) + ровный лёгкий слой SFX: по одному
   мягкому звуку на прилёт карточки/экрана, клик на действии, колокол на финале.
8. **Share caption.** См. «Share copy» ниже.
9. **User flow worth showing.** Не один тикет, а рабочий день владельца сервиса:
   посмотреть цифры → увидеть, что ИИ отвечает сам → откуда он берёт ответ → чем дожимает
   оператор → что панель знает о клиенте → что она может с клиентом сделать.

## What is this app?
Панель поддержки для VPN-сервисов: Telegram на входе, ИИ с базой знаний в середине, оператор
с шаблонами и полным доступом к аккаунту клиента на выходе — и статистика по всему этому.

## The angle
Не «ещё один хелпдеск», а витрина шести конкретных вещей, которые владелец VPN-сервиса
получает в одном окне. Видео идёт по настоящим экранам панели и на каждом держит ровно одну
строку пользы. Кульминация — не переписка, а **действие над аккаунтом клиента прямо из
карточки**: «Продлить подписку → Месяцев 3 → Применить», и дата в карточке меняется на глазах.
Резервный канал доставки в сюжет не входит.

## Hook (first 2-3 seconds)
Экран «Статистика» проявляется на чёрном, «Обращений сегодня» считает 0 → 128, рядом встают
ещё три метрики. Первое, что видит владелец сервиса, — его собственные цифры, а не логотип.

## Key moments (the middle)
- График «Обращения по дням» **рисуется линией** слева направо, под ним поднимается тепловая
  карта «Обращения по часам».
- Пузырь ИИ с бейджем **«ИИ»** отвечает клиенту сам.
- Экран **«База знаний»**: «24 чанка · используется ИИ для поиска», карточки чанков, и та,
  из которой пришёл ответ, подсвечивается синим кольцом; всплывают её ключевые фразы.
- Композер: **«/»** открывает панель шаблонов, оператор выбирает готовый ответ.
- **Карточка клиента**: вкладки «Профиль · Ключи · Рефералы · Обращения · Действия»,
  тариф, срок, трафик, устройства.
- **Действия над аккаунтом**: курсор жмёт «Продлить подписку», форма «Месяцев 3», «Применить» —
  и «Активен до» в карточке перещёлкивается с зелёной вспышкой, всплывает тост.

## Outro / punchline
Уход в чёрное, градиентная плитка «Х», «VPN Хелпдеск», строка
«Одна панель для поддержки VPN».

## User flow worth showing
Три бита, растянутые на шесть экранов:
1. **Вход** — владелец открывает статистику и видит нагрузку и скорость ответа.
2. **Ключевое действие** — ИИ отвечает по базе знаний, оператор дожимает шаблоном.
3. **Результат** — оператор меняет аккаунт клиента из той же панели, не переключаясь.

## Tone
- Preset: `app-store`
- Creative direction: чистая витрина продукта для владельца VPN-сервиса
- Interpretation: шесть чистых сцен, по одной строке пользы на сцену, аккуратные слайд-входы
  и склейки между экранами точно по биту, ровный лёгкий слой SFX. Никакой агрессии, никаких
  вспышек, никакой выдуманной статистики достижений. Копия — из проекта.

## Audio direction
- Role: тёплый деловой бед + ровный лёгкий слой акцентов (app-store)
- Music: `happy-beats-business-moves-vol-11-by-ende-dot-app.mp3` (warm and business-y, 114.84 BPM)
- Music treatment: старт 0.0, fade-in 0.5s, рабочая громкость 0.30, подъём до 0.33 на сцене
  действий, fade-out 23.4 → 25.0
- Music cue guidance: preset прочитан —
  `assets/music/cues/happy-beats-business-moves-vol-11-by-ende-dot-app.music-cues.json`.
  Границы сцен посажены прямо на сетку: 0.00 / 5.28 / 8.44 / 10.54 / 13.70 / 17.91 / 21.07.
  **Strong-cue локи (ровно 3, по политике):** **3.70s** — график рисуется (выкуп сцены 1);
  **8.96s** — подсвечивается чанк базы знаний, из которого пришёл ответ ИИ;
  **17.91s** — прилетает ряд действий над аккаунтом клиента (главное заявление ролика).
  Beat-grid: карточки метрик 1.60 / 2.12 / 2.65 / 3.18, тепловая карта 4.75, пузырь ИИ 5.80,
  чипы 9.50, шаблоны 11.06 / 11.60 / 12.12 / 12.65 / 13.18, карточка клиента
  14.22 / 14.76 / 15.28 / 15.81 / 16.34 / 16.86, действие 18.44 / 18.96 / 19.49 / 20.02,
  финал 21.59 / 22.12 / 22.65.
- Audio-reactive treatment: subtle. По `rms` мягко дышит фон-свечение активного экрана,
  по `bass` — присутствие подсвеченной карточки/чанка, по `treble` — ореол плитки логотипа.
  Никаких волновых форм, эквалайзеров, строба; на тексте амплитуда не применяется вовсе.
- SFX posture: ровный лёгкий слой (app-store) — по мягкому `drop` на прилёт карточки-метрики
  и экрана, `click` на действии курсора, `select` на выборе шаблона, тихий «успех» на
  применённом действии, колокол на логотипе. Всё в 0.45–0.70.
- Audio-coupled moments: прилёт четырёх карточек метрик; рисование графика; появление пузыря
  ИИ; подсветка чанка; выбор шаблона; клик «Продлить подписку»; применение действия; логотип.
- Restraint rule: ни одного звука без видимого движения; ничего агрессивного; музыка ≤ 0.33;
  на одну сцену не больше четырёх акцентов.

## Storyboard

### Scene 1 — «Статистика» — 5.28s (0.00 → 5.28)
Экран «Статистика» на `#0d0d12`: шапка «Статистика · данные за выбранный период»,
переключатель периода «Сегодня / 7 дней / 14 дней / 30 дней» с активным «14 дней».
Четыре карточки метрик прилетают по одной: **«Обращений сегодня»** (число считает 0 → 128),
«Первый ответ (команда) 42 сек», «Закрыто диалогов 96», «Ср. ответ (команда) 3 мин 10 сек».
Затем **рисуется график «Обращения по дням»** (линия `#4F8EF7` с градиентной заливкой,
плашка «сегодня · 128 обращ.»), под ним поднимается тепловая карта «Обращения по часам»
(«средние значения за 14 дней · пик в 21:00»).
Sequential/interaction: yes — четыре карточки по beat-grid 1.60 / 2.12 / 2.65 / 3.18,
счётчик в первой, отрисовка линии графика, стаггер столбиков тепловой карты с 4.75.
Audio intent: спокойное открытие, «всё под контролем».
Audio-coupled idea: мягкий `drop` на каждую карточку; чуть более весомый на отрисовку графика.
Music: бед, fade-in 0.5s, 0.28.
Transition mood: жёсткая склейка по биту (5.28s) → Scene 2

Sequential/interaction: yes — пузырь ИИ садится на beat-grid 5.80 с лёгким подъёмом снизу.
Audio intent: «сработало само», без триумфа.
Audio-coupled idea: тихий `drop` на прилёт пузыря.
Music: бед, 0.30.
Transition mood: жёсткая склейка по биту (8.44s) → Scene 3

### Scene 3 — «База знаний» — 2.10s (8.44 → 10.54)

## Source-fidelity note
Экран «Статистика» в текущей сборке показывает только четыре карточки метрик и таблицу
операторов: переключатель периода, `LineChart` и `HeatmapChart` временно убраны из
`StatisticsScreen` (`HIDDEN_FEATURES.md` §3, возвращаются одной правкой — компоненты живут
в `app/static/statistics.jsx`). В ролике они показаны, потому что «статистика» из четырёх
плашек не читается как преимущество. Все остальные экраны — ровно то, что в сборке сейчас.

## Delivered vs planned
- **Переходы: кроссфейд 0.32s → жёсткая склейка точно по биту.** Кроссфейд держал два
  полноэкранных экрана в кадре одновременно, и аудит раскладки честно считал это наложением
  текста. Вместо подавления предупреждений склейки переехали на сетку 114.84 BPM, а каждый
  экран получил собственный вход шапки — для тона `app-store` это даже чище.
- Всё остальное — по плану. `npx hyperframes check`: 0 ошибок, 0 предупреждений,
  77/77 проверок контраста проходят WCAG AA.
