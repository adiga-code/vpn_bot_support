# Brag Plan: VPN Хелпдеск (vpn_bot_support)

## Inspection rubric (Step 1)

1. **What is the app?** Веб-панель оператора поддержки для VPN-сервисов: тикеты приходят
   из Telegram через n8n, ИИ отвечает по базе знаний, оператор дорешает в трёхколоночной
   панели, ответ уходит обратно в Telegram.
2. **Funniest / most impressive claim.** Не шутка, а инженерное упрямство: когда Telegram
   отвечает `400 BUSINESS_PEER_USAGE_MISSING` и сообщение теряется, панель дожимает ответ
   **по MTProto от того же аккаунта поддержки** — «доставлено резервным каналом», жёлтые ✓✓.
   Рядом: `423 Locked` вместо `403`, потому что «тикет занят» и «нет доступа» — разные вещи.
3. **Visual hook.** Тёмная панель `#0d0d12` с синим `#4F8EF7` и пузырём ИИ в синей рамке;
   градиентная плитка логотипа `#4F8EF7 → #A855F7` с буквой «Х».
4. **What to show from real UI.** Список тикетов с пульсирующей красной точкой, пузыри
   переписки (клиент / ИИ с бейджем «ИИ» / оператор), кнопка «Взять в работу», панель
   шаблонов по «/», статус доставки ✓✓ / ✗.
5. **Shortest satisfying video.** ~21s: одно сообщение клиента → тикет → ИИ → оператор →
   провал доставки → резервный канал.
6. **Tone.** Preset `polished`. Direction: «тихий премиальный фильм про рабочий инструмент».
7. **Audio.** Ровный чистый бит (vol-12), редкие мотивированные SFX: клик по кнопке,
   тихий стук прилёта тикета, ошибка, мягкий колокол на выкупе.
8. **Share caption.** См. «Share copy» ниже.
9. **User flow worth showing.** Клиент пишет в Telegram → тикет в панели по вебсокету →
   ИИ отвечает по базе знаний → оператор забирает и отвечает шаблоном → доставка падает →
   резервный канал довозит ответ.

## What is this app?
Панель поддержки для VPN-сервисов: тикеты из Telegram, ответы из панели — с ИИ на базе
знаний, живым вебсокетом, несколькими ВПН-ами в одном окне и резервным каналом доставки
на случай, когда Telegram отказывает.

## The angle
Это не маркетинговый ролик про «стримлайн воркфлоу», а 21 секунда реальной работы тикета.
Видео целиком идёт внутри настоящего интерфейса и заканчивается на той функции, которую
обычно не показывают: сообщение **не доставилось** — и панель всё равно довезла ответ.
Угол: инструмент, который уже подумал про плохой день.

## Hook (first 2-3 seconds)
Чёрный кадр `#0d0d12`. Печатается один входящий пузырь Telegram — настоящая фраза из базы
знаний проекта: «По Wi-Fi работает, а на мобильном нет». Под ним — «21:47 · Telegram».
Никакого логотипа, никакого заголовка. Сначала клиент, потом продукт.

## Key moments (the middle)
- Пузырь клиента **становится строкой тикета**: вокруг него собирается левая колонка
  панели, строка встаёт наверх с пульсирующей красной точкой и пилюлей сервиса.
- Ответ ИИ прилетает в синей рамке с бейджем «ИИ» — по базе знаний, про белые списки.
- Курсор жмёт **«Взять в работу»**, статус тикета переключается на «В работе»,
  композер открывает панель шаблонов по «/».
- Ответ уходит — и получает **красный ✗ `BUSINESS_PEER_USAGE_MISSING`**.
- Через секунду крестик сменяется **жёлтыми ✓✓ и подписью «доставлено резервным каналом»**.

## Outro / punchline
Отъезд на всю трёхколоночную панель, затемнение, градиентная плитка «Х»,
«VPN Хелпдеск» и строка: «Тикеты из Telegram. Ответы из панели.»

## User flow worth showing
Три бита настоящей работы:
1. **Вход** — сообщение из Telegram превращается в тикет в панели (реалтайм).
2. **Ключевое действие** — ИИ отвечает по базе знаний; не хватило — оператор жмёт
   «Взять в работу» и отвечает шаблоном.
3. **Результат** — доставка падает, резервный канал довозит ответ, в переписке остаётся
   системная запись.

## Tone
- Preset: `polished`
- Creative direction: тихий премиальный фильм про рабочий инструмент — «панель, которая
  уже подумала про плохой день»
- Interpretation: длинные удержания, мало текста на экране, движение короткое и точное
  (0.3–0.5s), никаких вспышек и зумов. Копия — только настоящая из проекта. Уверенность
  через сдержанность: ни одной строки, которую нельзя прочитать.

## Format: landscape — 1920x1080

## Share copy (draft)
Тикет из Telegram, ответ ИИ по базе знаний, оператор в один клик — а когда Telegram

## Audio direction
- Role: ровный чистый бед + редкие мотивированные акценты (professional restraint)
- Music: `happy-beats-business-moves-vol-12-by-ende-dot-app.mp3` (steady & clean, 110 BPM)
- Music treatment: старт с 0.0, громкость 0.30, быстрый fade-in 0.6s, лёгкий подъём к
  сцене 4, fade-out под логотипом (19.8 → 21.2), чтобы финальный колокол отзвенел поверх
- Music cue guidance: preset прочитан —
  `assets/music/cues/happy-beats-business-moves-vol-12-by-ende-dot-app.music-cues.json`,
  tempo 109.96 BPM. Целевые strong cues: **9.29s** (клик «Взять в работу»),
  **13.11s** (красный ✗ провала доставки), **17.47s** (жёлтые ✓✓ — главный выкуп).
  Beat-grid окна для последовательных прилётов: пилюли сервисов 4.39 / 4.91 / 5.34,
  тикет 6.00, ответ ИИ 8.19, ответ клиента 8.74, панель шаблонов 10.37 / 10.93 / 11.46 / 12.02,
  системная запись 15.29, финал 20.75 / 21.28 / 21.84. Максимум 3 strong-cue лока на ролик.
- Audio-reactive treatment: subtle; по RMS/басу мягко дышит синее свечение активной
  строки тикета и присутствие карточки переписки. Никаких волновых форм, эквалайзеров,
  строба и пульсации текста.
- SFX posture: sparse — 5–6 акцентов за 21s, все мотивированы видимым действием
- Audio-coupled moments: печать пузыря клиента (тихие тики клавиш, прорежённые),
  прилёт строки тикета, клик курсора по «Взять в работу», открытие панели шаблонов,
  ошибка доставки, мягкий колокол на ✓✓ и на логотипе
- Restraint rule: ни одного звука без видимого движения на экране; ничего агрессивного;
  SFX 0.45–0.65, музыка не выше 0.32; ошибка доставки — сухая и короткая, не комедийная

## Storyboard

### Scene 1 — «Сообщение» — 4.2s (0.0 → 4.2)
Чёрный `#0d0d12`, пусто. По центру-слева печатается входящий пузырь Telegram
(`#1a1a24`, `rounded-2xl rounded-tl-md`): **«По Wi-Fi работает, а на мобильном нет»**.
Под пузырём мелко `#6b7280`: **«21:47 · Telegram»**. Пузырь дописывается к 1.55s и
держится до 3.85s — 2.3s осевшего времени (7 слов × 0.3s = 2.1s floor ✅).
Sequential/interaction: yes — текст печатается по символам, курсор-каретка мигает.
Audio intent: тишина комнаты, в которую входит один человек; бед уже идёт, но тихо.
Audio-coupled idea: тики клавиш по символам, прорежённые (каждый 3-й символ), 0.45.
Music: ровный бед, fade-in 0.6s, 0.28.
Transition mood: soft crossfade → Scene 2

### Scene 2 — «Тикет» — 3.7s (4.0 → 7.7)
Вокруг пузыря **собирается панель**: слева выезжает колонка списка тикетов, сверху —
ряд пилюль сервисов **«Все сервисы · 12»**, **«GruVPN · 7»**, **«NordSky · 5»** и чипы
разделов **«В работе · Ожидание · Очередь · ИИ · Закрытые»**. Строка нового тикета встаёт
наверх списка с пульсирующей красной точкой `#ef4444` и синей полоской слева `#4F8EF7`.
Одна читаемая строка в верхней полосе кадра (6.25 → 8.2):
**«Из Telegram — в панель»** (4 слова → floor 1.2s, осевшего времени 1.35s ✅).
Sequential/interaction: yes — пилюли сервисов прилетают одна за другой по beat-grid
(4.39 / 4.91 / 5.34, это чипы-акценты, не текст для чтения); строка тикета садится на 6.00
и дальше держится весь кадр.
Audio intent: система проснулась; аккуратный, не празднующий звук.
Audio-coupled idea: мягкий drop на посадку строки тикета; пилюли — без звука (не частить).
Music: бед продолжается, 0.30.
Transition mood: clean cut → Scene 3

### Scene 3 — «ИИ → оператор» — 4.5s (7.7 → 12.2)
Камера уходит в колонку переписки. Прилетает **пузырь ИИ** в синей рамке
(`#4F8EF7`/12 фон, `#4F8EF7`/25 граница) с бейджем **«ИИ»** в левом верхнем углу:
«Проверьте подключение и перезапустите приложение» — общий ответ, который не решает вопрос.
Клиент пишет «Уже пробовал. Не помогло.» —
в шапке переписки появляется кнопка **«Взять в работу»**, курсор подъезжает и **жмёт**
её (`// beat-locked: 9.29s`, strong cue 0.97). Статус тикета перещёлкивается на **«В работе»**.
Композер: оператор ставит **«/»**, снизу вверх открывается панель шаблонов
(`#13131a`, граница `#2a2a3a`) с плейсхолдером **«Поиск шаблонов...»** и двумя строками,
выбор — по первой.
Одна читаемая строка в полосе (9.88 → 12.2): **«ИИ не справился — зовёт оператора»**
(5 слов → floor 1.5s, осевшего времени 1.7s ✅).
Sequential/interaction: yes — симулируется курсор с кликом по кнопке и выбор шаблона;
панель шаблонов открывается на 10.37, строки прилетают по beat-grid 10.93 / 11.46,
выбор — на 12.02.
Audio intent: работа руками; короткий, точный, не громкий.
Audio-coupled idea: click на кнопке ровно в момент нажатия; тихий select на выборе шаблона.
Music: бед, 0.30.
Transition mood: clean cut → Scene 4

### Scene 4 — «Резервный канал» — 6.3s (12.2 → 18.5)
Ответ оператора уходит пузырём вправо (`#4F8EF7`/12). Под ним подпись
«Марина · 21:49 ✓». Через полсекунды галочка становится **красным ✗**, и строкой ниже
`#ef4444` моноширинным: **`✗ 400 BUSINESS_PEER_USAGE_MISSING`** (`// beat-locked: 13.11s`).
Пауза — кадр держит провал 2.2s, это важно.
На 15.29 появляется системная запись «повтор резервным каналом», а на 17.47 статус пузыря
**перещёлкивается на жёлтые ✓✓ `#eab308`** с подписью
**«доставлено резервным каналом»** (`// beat-locked: 17.47s` — главный выкуп ролика).
Читаемая строка в полосе (17.75 → 19.6): **«Telegram отказал. Ответ дошёл.»**
(4 слова → floor 1.2s, осевшего времени 1.3s ✅). Рамка пузыря идёт
фиолетовая → красная → жёлтая — ровно как в `dialogs.jsx`.
Sequential/interaction: yes — состояние доставки меняется по шагам на глазах:
✓ → ✗ + причина → ✓✓ + подпись.
Audio intent: короткий провал, тишина, затем разрешение; не драматизировать.
Audio-coupled idea: сухой короткий негативный акцент на ✗ (не комедийный);
мягкий колокол на жёлтых ✓✓.
Music: бед слегка подрастает к 0.32 на выкупе.
Transition mood: soft crossfade → Scene 5

### Scene 5 — «Панель целиком» — 6.0s (18.5 → 24.5)
Отъезд 18.5 → 19.3, затем ~0.9s чистого кадра: вся трёхколоночная панель — список,
переписка, карточка клиента справа. С 20.19 кадр уходит в `#0d0d12` полностью, и на
чёрном садится градиентная плитка `#4F8EF7 → #A855F7` с буквой **«Х»**
(`// beat-grid: 20.75`), под ней **«VPN Хелпдеск»** (21.28) и строка
**«Тикеты из Telegram. Ответы из панели.»** (21.84 → 24.5 — 2.7s, floor 1.5s ✅).
Sequential/interaction: none — только отъезд и посадка логотипа.
Audio intent: закрытие; последний звук звенит поверх уходящей музыки.
Audio-coupled idea: мягкий колокол на посадку плитки логотипа.
Music: fade-out 22.9 → 24.5 до 0.
Transition mood: —
